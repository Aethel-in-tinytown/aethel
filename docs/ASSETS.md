# Asset provenance

The initial UI code, procedural art recipes, favicon and bundled fonts were
supplied in `Aethel_Town.zip`. Its package metadata declares MIT; this repository
preserves the archive and does not invent an additional copyright assignment.

The town is generated in Canvas/Phaser from first-party building, terrain and
character recipes; no remote texture service is required. Font files are served
locally: Fraunces (normal and italic), Karla and Pixelify Sans. Their upstream
font licenses are included alongside the files in `web/assets/fonts/` and copied
into release assets. Preserve those notices when redistributing the web build.

Dependencies retain their package-provided licenses in their distributions.
